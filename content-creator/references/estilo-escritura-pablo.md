# Estilo de Escritura de Pablo Paredes

## Guía de Voz y Patrones Narrativos

Este documento complementa el análisis de frameworks de Aarón Benítez. Mientras ese documento extrae **estructuras de pensamiento**, este captura **tu forma de narrar**: las decisiones de puntuación, ritmo, tono y vocabulario que hacen que un texto suene a ti.

---

## 1. Puntuación Expresiva

### Punto y coma para contraste
Usas el punto y coma (;) para crear contrastes o secuencias causales en una sola línea:

```
"si los apagan, las ventas bajan; si los prenden, las ventas suben."
```

### Comillas angulares («») para interrupciones o énfasis
```
"pero muy poco «o en este caso nada» de tiempo prospectando"
```

**IMPORTANTE:** NO usar em dashes (—). Son señal clara de uso de IA.

### Paréntesis para aclaraciones conversacionales
```
"(casi nunca hay contratos de por medio)"
"(empezando por EE. UU.)"
```

### Comillas para distancia irónica o énfasis
```
"milagrosamente"
"responsabilidad"
"lo suficientemente bien"
```

## 2. Ritmo de Frases

### Frases cortas apiladas para impacto
No usas bullets. Usas líneas cortas que caen una tras otra:

```
Funcionó.
Pero la infraestructura era cara.
```

```
Pensar bien.
Diseñar mejor.
Y entender de verdad a las personas.
```

```
No siempre es falta de ganas.
Ni falta de conocimiento.
```

### "Y" para iniciar conclusiones
Empiezas frases con "Y" para dar peso a la conclusión:

```
"Y regresamos al principio."
"Y justo por eso, también es más competitivo."
"Y eso, aunque a muchos les da miedo, en realidad es una gran noticia."
```

---

## 3. Estructura de Contraste Temporal

Uno de tus patrones más fuertes es el contraste antes/después:

```
Hace un año, para lograr un filtro decente [...]
↓
Hoy, un año después, puedes lograr los mismos resultados [...]
```

```
Hace un año el moat era:
- Saber usar IA
- Tener el hardware

Hoy eso ya no alcanza.
```

---

## 4. Preguntas Retóricas como Pivote

Usas preguntas para cambiar la dirección del post:

```
"¿El problema? A la mayoría les da miedo usar una terminal."
```

```
"¿Por qué funciona?"
```

```
"¿Te ha pasado que haces una pregunta en una comunidad [...] y nadie responde?"
```

---

## 5. Listas Sin Formato de Lista

Cuando listas cosas, lo haces con texto corrido o con prefijos mínimos, no con bullets perfectos:

**Con prefijos simples:**
```
- Saber usar IA
- Tener el hardware
- Poder montar el sistema
```

**Con comillas angulares para énfasis inline:**
```
La UX, la UI, «el entendimiento real del usuario».
```

**Con "Porque" repetido:**
```
Porque no le pides a nadie que se "autodeclare experto".
Porque reduces el ida y vuelta innecesario.
Porque demuestras que ya hiciste parte del trabajo.
```

## 6. Vocabulario y Tono

### Coloquialismos mexicanos (con moderación)
```
"deja de hacerte wey"
"jaja"
```

### Inglés técnico sin traducir
```
"moat", "commodity", "early bird"
"Don't ask to ask. Just ask."
```

### Términos técnicos mencionados, no explicados
```
"ComfyUI, Unity, GPUs, pruebas infinitas, LoRas..."
"Three.js + Mediapipe"
```

### Autoironía / Vulnerabilidad casual
```
"Omitan mis caras; me sentía Tony Stark."
"No quiero sonar como un vendehumo."
```

### Palabras prohibidas (no usar)
Palabras demasiado rebuscadas, profesionales, o que simplemente Pablo no dice:
- empleos
- brecha
- abismal
- ocupación
- anhelar

**Alternativas más naturales:**
- empleos → trabajos, chambas
- brecha → diferencia, distancia
- abismal → enorme, brutal, gigante
- ocupación → trabajo, a lo que te dedicas
- anhelar → querer, buscar, extrañar

### Frases prohibidas (clickbait de pseudo-expertos)
Frases exageradas que suenan a gurú de IA o clickbait:
- "me voló la cabeza"
- "esto cambia todo"
- "esto es una locura"
- "no vas a creer lo que..."
- "el futuro ya llegó"
- "esto lo cambia todo para siempre"
- "revolucionario"
- "game changer"
- "mind-blowing"
- "increíble pero cierto"

**Alternativas más honestas:**
- En lugar de exagerar → describir qué hace y dejar que el lector juzgue
- En lugar de "me voló la cabeza" → "me llamó la atención", "me pareció interesante"
- En lugar de "cambia todo" → explicar qué cambia específicamente

```

### Contraste temporal
```

```

```

### Cita de tercero
```

```

## 9. Cierres que Funcionan

### Reframe filosófico
```
"ya no se trata de si puedes hacerlo...
sino de qué haces con eso."
```

### Frase corta contundente
```
"Ahí es donde está el nuevo juego."
"Esos milagritos nunca llegan."
```

### Tagline + CTA
```
"El futuro se construye hoy.
Regístrate gratis aquí:"
```

### Referencia circular (callback al inicio)
```
"No preguntes si puedes preguntar.
Solo pregunta.
«Don't ask to ask. Just ask»."
```

## 10. Lo que NO Haces (Anti-patrones de IA)

### No usas:
- ❌ Em dashes (—) — señal clara de IA
- ❌ Bullets perfectamente simétricos (•, ✓, →)
- ❌ Headers con emojis decorativos
- ❌ Frases de transición genéricas ("Dicho esto...", "En conclusión...")
- ❌ Listas numeradas largas (1. 2. 3. 4. 5...)
- ❌ Repetición de estructura perfecta (A es B. C es D. E es F.)
- ❌ Cierres con "Espero que esto te haya sido útil"
- ❌ Frases excesivamente pulidas sin imperfección
- ❌ Palabras rebuscadas: empleos, brecha, abismal, ocupación, anhelar

### Sí usas:
- ✓ Imperfección intencional ("jaja", frases incompletas)
- ✓ Puntuación variada (;, —, (), «», "")
- ✓ Mezcla de español e inglés natural
- ✓ Referencias a cultura pop sin explicar
- ✓ Datos específicos ($6,500, 2-3 horas diarias)

## 11. Imágenes para Posts

Los posts con imagen tienen mejor rendimiento. Pablo usa IA para generarse como personaje de película o escena icónica que represente el contenido.

**Estilo de imagen:**
- Pablo reemplazado por un personaje reconocible
- Escena que conecte con el tema del post
- Toque de humor o ironía
- Visualmente llamativo y shareable

**Ejemplos de combinaciones:**

| Tema del post | Escena/Personaje |
|---------------|------------------|
| Ventas, confianza, cerrar deals | DiCaprio en Wolf of Wall Street |
| Tecnología, decisiones, futuro | Neo/Morpheus en Matrix |
| Perseverancia, no rendirse | Rocky entrenando |
| Creatividad, locura, genio | Doc Brown en Back to the Future |
| Liderazgo, estrategia | Escena de guerra/batalla épica |
| Vulnerabilidad, honestidad | Escena dramática, iluminación suave |
| Velocidad, ejecución | Escena de carreras (F1, Fast & Furious) |
| Filosofía, reflexión | El Pensador de Rodin, pero versión moderna |

**Descripción debe incluir:**
- Personaje/película de referencia
- Escena específica
- Twist o elemento que lo haga único (ropa casual, elemento inesperado)
- Mood/iluminación si es relevante

## 12. Protección de Voz Natural

El objetivo es proteger la voz natural del autor, no pulirla.

### Restricciones al reescribir
- Usar frases cortas
- Usar lenguaje simple
- Evitar framing motivacional
- Evitar consejos genéricos
- Evitar transiciones de relleno

### Control de calidad
- Identificar frases escritas para impresionar en lugar de explicar
- Señalar frases vagas en lugar de reescribirlas automáticamente
- Preservar la franqueza aunque se sienta filosa

### Reglas de output
- No suavizar bordes
- No agregar "energía"
- No agregar "estilo"
- No hacer el texto más "profesional"

## Checklist de Autenticidad

Antes de publicar, pregúntate:

- [ ] ¿Suena como lo diría en una conversación?
- [ ] ¿Hay al menos una imperfección intencional?
- [ ] ¿Evité la simetría perfecta en las listas?
- [ ] ¿El cierre es contundente, no genérico?
- [ ] ¿Usé puntuación variada (no solo puntos y comas)?
- [ ] ¿Hay un contraste o tensión clara?
- [ ] ¿Hay una imagen sugerida que conecte con el contenido?
